# 面向玩家的产品化改进建议

> 目标读者：产品/开发。本文档从「不懂技术、只想省事搬砖的游戏玩家」视角，系统梳理当前控制台在**售卖化、易用性、信任感**上的差距与改进建议。
>
> 背景：平台计划对外售卖，直接面向普通梦幻西游玩家。当前界面偏向「工程师仪表盘」，需要转向「玩家保姆」。
>
> 状态：已归纳并纳入 [macOS 控制台后续开发路线](macos-dashboard-roadmap.md)（2026-08-02）。所有引用的现状均基于当前 `web/src` 前端实现。

---

## 一、核心矛盾

当前产品对内是一个功能完整的自动化控制台，但对一个付费玩家而言存在三条主线问题：

1. **看不懂**——满屏技术黑话与英文标签，玩家无法建立信任。
2. **不敢用**——不懂技术的人对自动化工具的第一恐惧是「失控 / 封号 / 把号搞坏」，当前界面完全没有安抚这种心理。
3. **不好用**——一个个任务手动启动太累，缺少「一键搬砖 / 定时挂机」这类真正的付费理由。

产品化的核心方向：**从「让玩家操作工具」转变为「让工具替玩家干活」。**

---

## 二、术语与文案：把「黑话」翻译成人话（P0）

普通玩家不认识技术词汇，看到英文标签和统计学口径会觉得像半成品，直接损害付费意愿与信任。

### 需要替换的英文标签（eyebrow / 状态码）

| 现状 | 位置 | 问题 | 建议 |
|---|---|---|---|
| `MACOS AUTOMATION DECK` | 顶栏副标题 | 玩家不认识 | 删除或改为「梦幻西游挂机助手」 |
| `TASK CONTROL · 127.0.0.1` | 任务面板 hero | IP 地址吓人 | 「任务中心」 |
| `VERIFIED ON MACOS` | 已适配任务 | 无信任价值 | 「已支持的任务」 |
| `GAME DATA · SOURCE SNAPSHOTS` | 数据面板 hero | 完全无法理解 | 「我的收益」 |
| `7 DAY SIGNAL` / `AUTOMATED SNAPSHOT` / `CAPTURE HISTORY` | 数据面板 | 黑话 | 「近 7 天走势」「记录数据」「历史记录」 |
| `IDLE` / `preparing` / `stopping` | 状态显示 | 英文状态码 | 「空闲」「准备中」「停止中」 |

### 需要换成人话的名词

| 技术词 | 玩家的说法 |
|---|---|
| 采集 / 快照 | 记录 / 记一下数据 |
| 指标 | 金币 / 经验（直接说具体的） |
| schema / 区间 / 净变化 | 不出现，改口语 |
| 首尾有效快照差值 | 今天比 X 天前多了多少 |

**原则：界面上不出现任何玩家需要「翻译」才能理解的词。**

## 三、信任与安全感：消除「会不会把号搞坏」的恐惧（P0）

不懂技术的玩家用自动化工具时最怕失控。当前界面把技术日志、英文状态直接暴露，反而加剧恐惧。

### 3.1 运行时给「安全感」而非「技术日志」

- **现状问题**：任务动态区滚动大量技术日志（`TaskPanel.tsx` 日志窗口），玩家看到一堆滚动文字甚至英文会以为出错。
- **建议**：运行时主视图改为「**正在做：第 3 个任务（师门任务）· 预计还需 8 分钟**」这种一句话进度，技术日志折叠进「查看详情」，默认不显示。

### 3.2 紧急停止要显眼且让人安心

- 「停止任务」按钮要足够大、足够醒目。
- 停止后明确告知：「**已安全停止，游戏已回到主界面，不会卡住。**」——消除「停了会不会卡在半路」的担忧。

### 3.3 权限引导必须图文化

- **现状问题**：出现「开启屏幕录制权限」「开启辅助功能权限」提示时，玩家根本不知道去 macOS 哪里点。这是**新手流失的最大关口**。
- **建议**：做成分步图文/短视频向导——「第一步：打开系统设置 → 第二步：点隐私与安全性 → …」，每步配截图。

### 3.4 错误提示给「人话 + 出路」

- **现状问题**：错误多为抛出原始错误信息。
- **建议**：所有错误都是「**发生了什么 + 我该怎么办**」的结构。
  - ✅「没有找到游戏窗口，请确认游戏已经打开并显示在屏幕上 → [重新检测]」
  - ❌「window not found」

## 四、核心体验：让工具替玩家干活（P0 / P1）

这是决定「值不值得付费」的部分。当前只能一个个手动启动任务，缺少真正的杀手锏。

### 4.1 「一键全部」按钮（P0，最重要的卖点）

- 早上点一下，自动按顺序把今天所有日常/搬砖任务跑完。
- **这才是付费理由**——单个任务手动启动对挂机党毫无吸引力。

### 4.2 任务勾选与排序（P1）

- 让玩家自己勾选今天要跑哪几个任务、拖动调整顺序。
- 记住玩家的选择，第二天默认沿用。

### 4.3 定时 / 预约（P1）

- 「每天早上 8:00 自动开始」——挂机党刚需。
- 支持「跑完自动关闭 / 睡眠」等收尾选项。

### 4.4 大进度总览（P1）

- **现状问题**：「今日完成 X / 总数」（`TaskPanel.tsx` 区域）只是一行小字，视觉上不突出。
- **建议**：做成显眼的大进度条 +「今日 5/8 完成，预计还需 25 分钟」，玩家一眼看完当天状态。

---

## 五、数据展示：玩家只关心「我赚了多少」（P1）

当前数据面板像一份财报，堆满统计学口径，玩家无感。

### 5.1 首屏一句话收益

- 最显眼位置放大字：「**今天赚了 12,340 金币，比昨天多 8% ↑**」——带涨跌箭头、正向用绿色。
- 这是玩家每天真正想看的第一件事。

### 5.2 删除或折叠玩家无感的统计口径

以下卡片对普通玩家没有决策价值，建议删除或折叠进「详细数据」二级页：

- 平均每次变化 / 最近一次变化（语义接近，可合并）
- 区间高 / 低
- 首尾有效快照差值
- **采集成功率**——这是系统健康度，不该和金币/经验业务指标混在一张网格里

### 5.3 趋势图配人话解读

- 保留走势图，但配一句白话：「最近 3 天收益稳定上涨 📈」。
- 图上可叠加任务事件标记，直观看出哪个任务贡献了收益（P2）。

### 5.4 隐藏对玩家无用的功能

- CSV 导出对普通玩家没用，藏进高级/详细区。

## 六、"今日任务" Tab 的定位问题（P1）

- **现状问题**：数据面板的「今日任务」读的是游戏内日程页快照，与任务面板里每张卡片的「今日已完成」是**两套数据**，玩家容易混淆到底哪个是准的。
- **建议**：合并为一套口径——要么把游戏日程状态直接挂到任务卡上，要么去掉独立 Tab，避免「同一件事两个地方显示不一样」。

---

## 七、不要暴露未完成的功能（P1）

- **现状问题**：角色资源里「银币 / 仙玉 / 活力 / 评分」直接显示「待接入」（`GameDataViews.tsx`）。玩家会理解为「这功能坏了」，损害信任。
- **建议**：未接入的字段直接隐藏，或明确标注「即将推出」并做成灰态占位，绝不用会被误读为「故障」的措辞。

---

## 八、商业化基础（P2）

要卖钱，需要补齐产品化的底座：

- **首次使用引导（onboarding）**：第一次打开走一遍向导——连接游戏 → 开权限 → 跑一个测试任务，不让玩家自己摸索。
- **账号 / 授权体系**：登录、激活码 / 订阅、到期提示。当前是纯本地工具，无法售卖。
- **功能清单透明**：明确「已支持哪些任务、哪些还在开发」，管理预期。
- **异常主动提醒**：连续多次采集失败、或指标异常掉落时给出醒目提示，比藏在成功率里有用。

## 九、优先级汇总

| 优先级 | 事项 | 为什么 |
|---|---|---|
| **P0** | 术语中文化、隐藏未接入功能 | 改动小、见效快，立刻让界面「不像半成品」 |
| **P0** | 一键全部 + 新手引导 | 直接决定玩家会不会用、敢不敢用 |
| **P0** | 权限引导图文化、错误提示人话化 | 新手流失最大关口 |
| **P0** | 运行时安全感文案、显眼紧急停止 | 消除封号/失控恐惧 |
| **P1** | 数据面板极简化（今日收益一句话） | 提升「值得付费」的感知 |
| **P1** | 定时预约、任务勾选排序、大进度条 | 挂机党核心付费点 |
| **P1** | 统一「今日任务」数据口径 | 消除混淆 |
| **P2** | 登录/激活码、事件标记、主动异常提醒 | 商业化底座与增值体验 |

---

## 十、建议的第一步

在 P0 中，推荐先做**「术语中文化 + 隐藏未接入功能」**：改动范围集中在前端展示层，风险低、见效最快，能立刻让整个界面从「半成品工程工具」变成「像样的玩家产品」，为后续的一键全部、新手引导等大功能铺好体验基线。
